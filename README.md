# 15 Puzzle AI

The 15 Puzzle solved with a selection of different AI algorithms.

## Description

This project implemented: A Search, Breadth-First Search, Depth-First Search, General Search, Greedy Best-First Search and Iterative Deepening Search. These AI algorithms are used solve the 15 Puzzle.

## Instructions

1. **Compile**
```bash
javac *.java
```

2. **Run**
```bash
java Main
```
